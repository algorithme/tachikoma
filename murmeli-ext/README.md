# murmeli-ext

Reserved for Murmeli's TypeScript Visual Studio Code extension.

The extension will connect to the independent Rust process in [`../core`](../core). The current milestone implements only core's local Hello world server. Extension behavior, connection protocol, process management, packaging, and build tooling will be decided in later milestones.

There is no extension package or executable yet. Use the [root README](../README.md) to run and test core.
