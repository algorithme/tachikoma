# tachikoma-ext

Reserved for an optional future TypeScript Visual Studio Code client for Tachikoma.

The current implementation is the independent Rust process in [`../core`](../core), serving a local Hello world page. This directory has no client implementation or selected connection protocol. Client behavior, process management, packaging, and build tooling remain for later milestones.

There is no extension package or executable yet. Use the [root README](../README.md) to run and test core.
